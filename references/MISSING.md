# Papers not in the collection

These could not be downloaded by script (most publisher sites block automated downloads). After saving a PDF from a browser, put it in any folder and run `python ingest_downloads.py <folder>`: it matches the file to the paper, files it under `open_access/` or `local_only/` by licence, renames it with the paper's title and updates the index (then run `python build_index.py`).
