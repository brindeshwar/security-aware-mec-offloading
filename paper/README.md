# Paper source

`paper.tex` + `refs.bib` use the official IEEE Access LaTeX class (template of 2026-05-13). The template, its fonts and the
bibliography style belong to IEEE and are **not stored in this repository**. Fetch them once:

```bash
python setup_template.py      # downloads the IEEE template into ./ieee and applies three small edits (see the script)
python build.py               # pdflatex + bibtex + pdflatex x2  ->  paper.pdf
```

The edits make the page footer read "PREPRINT - NOT PEER REVIEWED" and replace the IEEE Access logo in the header by a plain
"PREPRINT" label; the layout is otherwise IEEE's.

Figures and tables are not copied here: the paper reads them from `../results/figures` and `../results/tables`, which are
generated by the scripts in `../simulation` (`make_figures.py`, `export_latex.py`). Every number in the text comes from
`../results/tables/numbers.tex`.

`build.py` uses `../.local/tools/TinyTeX` if it exists (a portable TeX Live) and otherwise the `pdflatex` on your PATH.
